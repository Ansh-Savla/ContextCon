# Project skills

Project-local skills are stored under `.agents/skills/` and are available after Codex refreshes or starts a new session.

## General

- `hackathon-agent-builder`: convert a paid service workflow into an end-to-end agent with CrustData-backed evidence, clear exception handling, and a demoable result.
- `frontend-craft`: produce distinctive, accessible, workflow-centered interfaces and inspect the rendered result when browser tooling is available.
