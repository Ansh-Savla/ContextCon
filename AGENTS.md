# Project instructions

Before planning or editing this project, read [`.codex/steering.md`](.codex/steering.md). Its CrustData-first rule is a strict project requirement.

Use the matching skill under [`.agents/skills/`](.agents/skills/) when a task fits it. For CrustData work, use the official CrustData skills and tools, then apply the hackathon-specific constraints in the steering file. The steering file takes precedence over generic skill examples.

Keep secrets out of source control and logs. Do not contact real people, send outreach, or create external actions as part of the hackathon workflow.
