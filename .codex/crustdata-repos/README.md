# CrustData public source repositories

Each repository below is registered as a Git submodule pointing to its CrustData upstream, preserving the full history and tags without copying upstream repository objects into this project's Git database. Clone this project with `--recurse-submodules` to populate the source directories. Check each repository's own license and README before reusing code or assets.

| Repository | Contents | Upstream |
|---|---|---|
| `tools` | Open-source AI agent implementations and API usage examples | https://github.com/crustdata/tools |
| `skills` | Current CrustData agent skills, MCP/plugin manifests, and examples | https://github.com/crustdata/skills |
| `crustdata-cursor-plugin` | Cursor plugin and CrustData connection examples | https://github.com/crustdata/crustdata-cursor-plugin |
| `vercel-crustdata-template` | Vercel starter/template using CrustData | https://github.com/crustdata/vercel-crustdata-template |
| `n8n-nodes-crustdata` | n8n integration source and usage material | https://github.com/crustdata/n8n-nodes-crustdata |
| `benchmarks` | People search and technographics benchmark code, data, and methodology | https://github.com/crustdata/benchmarks |
| `claude-gtm-skills` | Earlier CrustData agent skill examples | https://github.com/crustdata/claude-gtm-skills |
| `homebrew-tap` | Official CLI distribution/tap material | https://github.com/crustdata/homebrew-tap |

The CrustData GitHub organization also lists `dify-plugins`, a 1.56 GB fork of the Dify plugin catalog. It is excluded because it is upstream Dify material and its repository tree contains no CrustData-specific paths. The other eight public organization repositories are included here.
